# AeroSpace — window manager

Everything starts with **alt** (⌥). `alt` = look/go · `alt-shift` = take the window with you.

## Help
| Keys | Action |
|------|--------|
| `alt-shift-/` (alt-?) | Open this cheatsheet (floating window) |

## Focus & move windows
| Keys | Action |
|------|--------|
| `alt-h` / `alt-j` / `alt-k` / `alt-l` | Focus window left / down / up / right |
| `alt-shift-h/j/k/l` | Move the window left / down / up / right |
| `alt-enter` | New kitty terminal |
| `alt-shift-q` | Close window |

## Workspaces
| Keys | Action |
|------|--------|
| `alt-1` … `alt-9` | Go to workspace 1–9 (1 term · 2 browser · 3 chat · 4 notes) |
| `alt-shift-1` … `alt-shift-9` | Send window to workspace N and follow it |
| `alt-tab` | Jump back to the previous workspace |
| `alt-shift-tab` | Move the whole workspace to the next monitor |

## Layout & size
| Keys | Action |
|------|--------|
| `alt-f` | Fullscreen toggle |
| `alt-t` | Tiles: toggle side-by-side ⇄ stacked |
| `alt-a` | Accordion: one big window, others peek at the edge |
| `alt-shift-space` | Float ⇄ tile this window |
| `alt--` / `alt-=` | Shrink / grow window |
| `alt-r` then `h/j/k/l` | Resize mode (`=` balance, `esc` done) |

## Service mode (alt-shift-;)
| Keys | Action |
|------|--------|
| `r` | Reset / flatten a messed-up layout |
| `f` | Float ⇄ tile |
| `backspace` | Close all windows except the focused one |
| `alt-shift-h/j/k/l` | Join with neighbour (make a nested split) |
| `esc` | Reload config and leave |
