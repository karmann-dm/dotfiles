# kitty — terminal

kitty stays simple; **tmux** does splits/tabs. These are kitty's own keys.

## Everyday
| Keys | Action |
|------|--------|
| `cmd-c` / `cmd-v` | Copy / paste (selecting with the mouse copies too) |
| `cmd-=` / `cmd--` / `cmd-0` | Font bigger / smaller / reset |
| `cmd-n` | New OS window |
| `cmd-k` | Clear screen + scrollback |
| `cmd-f` | Open scrollback in less, then `/` to search |
| `cmd-ctrl-,` | Reload kitty.conf |

## Hints (select things on screen by keyboard)
| Keys | Action |
|------|--------|
| `ctrl-shift-e` | Pick a URL on screen and open it |
| `ctrl-shift-p` then `f` | Pick a file path and insert it at the prompt |
| `ctrl-shift-p` then `l` | Pick a whole line and insert it |
| `ctrl-shift-p` then `w` | Pick a word and insert it |

## Unicode & misc
| Keys | Action |
|------|--------|
| `ctrl-cmd-space` | Emoji / unicode picker (macOS) |
| `cmd-,` | Open kitty.conf in an editor |
